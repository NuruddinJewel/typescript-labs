## 📖 About This Project

This repository is a collection of **practical coding problems** designed to test and strengthen the understanding of core TypeScript concepts. Each problem focuses on one idea, making it possible to learn step by step, from simple types to real object-oriented design.

The goal is to **think in types** and write safer, cleaner code. It is suitable for beginners as well as anyone revising TypeScript fundamentals.

## 🧠 Concept Overview

### 🔤 Basic Types

Basic types are the foundation of TypeScript. Giving variables clear types helps catch mistakes before the code even runs.

### 🎛️ Optional, Default & Rest Parameters

These features make functions adapt to different situations: inputs that can be skipped, values that fall back to defaults, and any number of arguments gathered together.

### 🔒 Readonly Tuples

Tuples keep a strict structure, and `readonly` makes sure the data cannot be changed by accident.

### 📐 Interfaces

Interfaces define the shape of data. They make code easier to read, share, and maintain.

### 🔍 Type Narrowing

When a value could be more than one type, narrowing makes it possible to check it safely and work with it confidently.

### 🧬 Generics

Generics allow code to be written once and used everywhere, without giving up type safety.

### ⏳ Promises

Promises handle code that finishes later, such as fetching data or waiting for a timer, while keeping every result properly typed.

### 🏛️ Object-Oriented Programming

OOP builds well-structured programs using four pillars:

| Pillar               | Idea                                     |
| -------------------- | ---------------------------------------- |
| 🛡️ **Encapsulation** | Keep data safe and hidden inside classes |
| 🧬 **Inheritance**   | Reuse and extend existing classes        |
| 🎭 **Polymorphism**  | Same action, different behavior          |
| 🎨 **Abstraction**   | Show what matters, hide the complexity   |
